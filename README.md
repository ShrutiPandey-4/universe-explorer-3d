# 🌌 Universe Explorer 3D

An interactive 3D cosmic visualization built with Three.js and WebGL.

## ✨ Features

- Interactive 3D universe
- Procedural star field
- 30,000+ galaxy particles
- Spiral galaxy generation
- Animated solar system
- Celestial object information panel
- Raycaster-based object selection
- GLSL particle glow shaders
- Interactive camera controls
- Responsive interface

## 🛠️ Tech Stack

- JavaScript
- Three.js
- WebGL
- GLSL
- Vite
- HTML
- CSS

## 🚀 Run Locally

```bash
npm install
npm run dev
